# Sushmita.exe — Developer Portfolio

A responsive React + Vite portfolio with a rose-glow theme, light/dark mode toggle, an animated cartoon developer character, looping background music, famous GIF memes, projects, experience, achievements, LeetCode profile link, and contact cards.

## Run locally

1. Install Node.js (LTS).
2. In this folder run:
   ```bash
   npm install
   npm run dev
   ```
3. Open the local URL printed by Vite.

## Notes

- LeetCode contest rating attempts to load from a public stats endpoint; if that endpoint is unavailable or blocked by CORS, the portfolio keeps the profile link as the fallback.
- Click the music control to start or stop the looping background tune. Browsers require this user interaction before they allow audio playback.
- GIF memes require an internet connection.
- Contact links point to the supplied email, GitHub, LinkedIn, and Instagram profiles.
